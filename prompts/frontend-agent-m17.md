## 任务

### F1 · 占位背景统一为中性浅色

按 §34.3 逐条做：

1. **★ 用语义令牌，不要写死颜色。** 必须**同时**满足明暗两态：
   - 浅色主题 → **米白 / 浅灰**（用户要的效果）
   - 深色主题 → **深中性**（**不能是白的** —— 浅色占位在深色下会刺眼，
     M7 的 V7 就是处理这个问题的）
   - **不要** `bg-gray-100` 这类固定色，更不要十六进制
2. **删除** `CATEGORY_TINTS` 与 `TINTS` —— 它们的存在就是「按分类上色」这个被否掉的设计。
3. **删除** `TOOL_TYPE_META[*].placeholderClass` 的**颜色部分**。
4. **`categoryTintClass()` 不要保留成「仍然接受 slug 但忽略它」的函数** ——
   那会留下误导性的签名。改成**无参常量或零参函数**，并更新 3 处调用点
   （`ToolCard` / `ToolImageGallery` / `MyToolsPage`）。
5. **必须保留**：
   - 大号类型图标（`size-16` / `size-12`，`text-foreground/55` 一类语义令牌）
   - 「有封面但加载失败 → 回退占位」的行为（M7 建的）
   - 占位与真实封面**同一个盒子**（避免卡片跳动，docs/04 §9）

### F2 · 对比度**重新量**（不是沿用旧数字）

§34.5①：M7 量过的是**彩色渐变**上的数字，换了背景必须复测。
占位上的类型图标 ≥ 3:1（非文本），任何叠加文字 ≥ 4.5:1。
**给出浅色与深色下的实际令牌值与实测对比度。**
