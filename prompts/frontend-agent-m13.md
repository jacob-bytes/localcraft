## 任务

### D1 · 页脚恢复为「始终渲染」，内容按 §28.6 分两组

**一个 `<footer>` 元素**，位于 `AppShell`：

| 内容 | 显示范围 | 条件 |
| --- | --- | --- |
| `localcraft v{app_version}` + ` · API {api_version}` | **所有 AppShell 页** | 始终 |
| `portal.footer_tagline`（新字段） | **所有 AppShell 页** | 非空时 |
| `footer_org` / `footer_contact_email` / `footer_contact_phone` / `footer_notice` | **仅门户列表页与工具详情页** | 各自非空时 |

要点：

1. **页脚元素本身始终渲染** —— 因为版本行始终在。§27.4 那条「字段全空则整个页脚不渲染」
   已废止（它建立在「原本没有页脚」的错误前提上）。
2. **版本行与标语回到「全站显示」**，与 M12 之前一致。`/me`、`/admin` 也要有。
3. **4 个配置字段仍只在门户相关页**（用户保留了这个范围选择）。
   注意它们与版本行在**同一个 `<footer>` 内**，不要造两个页脚元素。
4. **邮箱/电话的防御性降级必须保留**（§27.4 仍有效）：不像邮箱/电话就渲染纯文本、
   不生成 `<a>`。
5. `<footer>` + `aria-label="站点信息"` 保留。
